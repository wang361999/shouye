# ET Studio 邮箱 SMTP 配置指南

## 概述

ET Studio 使用 SMTP 协议发送邮件，用于用户注册验证、系统通知等功能。配置入口位于管理后台：

> 管理后台 → 系统设置 → 安全设置 → 📧 邮箱服务配置 (SMTP)

---

## 配置步骤

### 第一步：获取邮箱授权码

大多数邮箱服务商不允许直接使用登录密码发送 SMTP 邮件，需要单独获取 **SMTP 授权码**。

#### QQ 邮箱
1. 登录 QQ 邮箱网页版
2. 进入 **设置 → 账户**
3. 找到「POP3/IMAP/SMTP/Exchange/CardDAV/CalDAV服务」
4. 开启 **IMAP/SMTP 服务**
5. 按提示发送短信验证后获取 **16位授权码**
6. 保存好授权码，配置时使用

#### 163 网易邮箱
1. 登录 163 邮箱网页版
2. 进入 **设置 → POP3/SMTP/IMAP**
3. 开启 **IMAP/SMTP 服务**
4. 按提示发送短信验证后获取 **授权码**
5. 保存好授权码，配置时使用

#### Gmail
1. 进入 Google 账户安全设置
2. 开启 **两步验证**
3. 生成 **应用专用密码**（App Password）
4. 选择"邮件"应用，生成16位密码
5. 使用该密码作为 SMTP 密码

#### 腾讯企业邮箱
1. 登录企业邮箱网页版
2. 进入 **设置 → 客户端设置**
3. 开启 **IMAP/SMTP 服务**
4. 生成 **客户端专用密码**
5. 使用该密码作为 SMTP 密码

---

### 第二步：填写 SMTP 配置

在安全设置页面的「邮箱服务配置 (SMTP)」区域填写以下信息：

| 字段 | 说明 | 示例 |
|------|------|------|
| **SMTP 服务器地址** | 邮箱服务商提供的 SMTP 服务器域名 | `smtp.qq.com` |
| **SMTP 端口** | SMTP 服务端口 | `587` 或 `465` |
| **SMTP 用户名** | 发件邮箱地址（完整邮箱） | `yourname@qq.com` |
| **SMTP 密码/授权码** | 邮箱的 SMTP 授权码（不是登录密码） | `abcdefghijklmnop` |
| **发件人名称** | 收件人看到的发件人名称 | `ET Studio` |
| **SSL/TLS 加密** | 是否启用 SSL/TLS 加密传输 | 建议开启 |

---

### 第三步：保存并测试

1. 填写完所有字段后，点击页面底部的 **保存设置** 按钮
2. 在「测试邮件」区域输入你的 **收件邮箱地址**
3. 点击 **发送测试邮件** 按钮
4. 检查收件箱，如果收到标题为 `[ET Studio] 邮件配置测试` 的邮件，说明配置成功

## 常见问题排查

### 发送失败：SMTP 配置不完整
请确保至少填写了 SMTP 服务器地址和用户名，并点击保存后再测试。

### 发送失败：连接超时
- 检查服务器防火墙是否放行了对应端口（587/465）
- 确认 SMTP 服务器地址是否正确
- 部分云服务器可能屏蔽了 25 端口，建议使用 465 或 587

### 发送失败：认证失败
- 确认使用的是 **授权码** 而不是登录密码
- QQ邮箱和163邮箱必须使用授权码
- 检查用户名是否为完整的邮箱地址

### 发送失败：SSL/TLS 错误
- 端口 465 需要开启 SSL/TLS 加密
- 端口 587 通常使用 STARTTLS，可以不开启 SSL 选项
- 如果不确定，先尝试端口 465 + SSL 开启

### 测试邮件未收到
- 检查垃圾邮件/垃圾箱文件夹
- 确认收件地址填写正确
- 查看服务器日志是否有详细错误信息

---

## 安全建议

1. **不要使用个人主邮箱** 作为发件邮箱，建议创建专用邮箱
2. **授权码保密**，不要泄露给他人
3. **定期更换** SMTP 授权码
4. 如果不需要邮件功能，可以不配置 SMTP，不影响其他功能使用
